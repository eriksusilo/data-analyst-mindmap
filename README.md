# Data Analyst Mind Map
### _Interactive Mind Map of Data Analyst Domains and Skills_

#### Welcome to my first project! 
> This is the Mind Map of Data Analyst, an interactive mind map designed to help anyone to understand the data analytics ecosystem, ranging from Hard Skills and Soft Skills to Self Development to Career Paths.
> Created with a passion for learning and sharing within the data community
#### AI-Augmented Development
This project was built using a collaborative workflow between human domain expertise and Generative AI tools (Claude & Gemini).
+ Human Input: Strategic domain knowledge, mapping of data analyst career paths, and UI/UX direction.
+ AI Input: Technical assistance in SVG path mathematics, interactive JavaScript logic, and code optimization.

>I believe that the future of work lies in the synergy between human intuition and AI efficiency. This project serves as a practical experiment in AI-augmented development, showcasing how AI can accelerate execution while maintaining high standards of domain accuracy.


### Live Demo

View the interactive map here: [Data Analyst Mind Map](https://eriksusilo.github.io/data-analyst-mindmap/)

### Key Features

+ Interactive & Draggable: You can move nodes around to visualize the relationships between skills more clearly
+ Font Scaling (A+/A-): Adjust text size for optimal readability and eye comfort
+ Domain Toggle: Hide or show specific categories (Hard Skills, Soft Skills, Context)
+ Zoom in and Zoom out the map


### What is Covered?
#### This map covers several major domains:

+ Technical Skills: SQL, Python/R, Statistics, ETL
+ Analytics Types: From Descriptive to Prescriptive analytics
+ Tools: Power BI, Tableau, BigQuery, and more
+ Soft Skills: Business Acumen, Critical Thinking, Storytelling
+ Career Path: Industry specializations and data career trajectories
+ etc

### Technologies Used

+ HTML5 & SVG for structure and vector graphics
+ CSS3 (Modern UI) featuring backdrop-filter effects and animations
+ Vanilla JavaScript for interaction logic, zooming, panning, and drag-and-drop functionality
